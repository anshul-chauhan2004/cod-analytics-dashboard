# COD Analytics Dashboard

A modern, high-performance Changeover Duration (COD) analytics and operational insights dashboard for fulfillment centers.

## Features
- **Local Browser Processing**: Parses and analyzes single or multi-file CSV/XLS exports directly in-browser.
- **Persistent Workspace**: Uses browser IndexedDB to persist loaded datasets across page refreshes.
- **Interactive Multi-Dimensional Analytics**:
  - Overview KPI metrics & bucket distributions
  - Defaulter Analysis & associate rankings
  - Process Group breakdown
  - Daily & Weekly performance trends
  - Floor & MOD dimensions
  - Dedicated Bin Type (`lc_category`) & Bin Usage (`bin_usage_type`) analysis
  - Associate 360° deep dive
  - Event Explorer & Data Quality inspection
- **Zero Backend Required**: Pure client-side static web application.

## Quick Start
Open `index.html` in any modern web browser or deploy as a static site to Vercel, Netlify, or GitHub Pages.
